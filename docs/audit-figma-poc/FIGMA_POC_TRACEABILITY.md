## 1. Como ler

**Coluna Figma** (duas origens):
- **Inspecionado** — texto/valor lido no próprio Figma, com o id do nó (`8:xxxx` = telas do produto; `13:xxxxx` = expansão social; `10:x` = componentes). Os frames são **especificações estáticas** ("interações não conectadas"): a matriz compara a PoC com o que está desenhado/escrito, não com um protótipo navegável.
- **—** — recurso da PoC (ou regra técnica) sem elemento correspondente no Figma.

**Estado atual** (vocabulário do roteiro): Implementado e funcional · Implementado parcialmente · Visual apenas · Implementado de outra forma · Ausente · Não verificável · Obsoleto ou conflitante.
Nenhuma linha foi classificada como "funcional" sem leitura do caminho de código relevante; onde um comportamento só foi inferido, a coluna Evidência diz isso. *Nenhum fluxo foi executado em navegador* (ver `VALIDATION_PLAN.md`); as exceções verificadas ao vivo estão indicadas (TR-011).
"Visual apenas" (existe só como aparência, sem comportamento) **não ocorreu**: nenhum elemento da PoC é só casca. Onde o Figma desenha algo que a PoC não tem, o estado é "Ausente" (ou "Parcialmente", se há equivalente incompleto).

**Correspondência e "deu bind"** (roteiro §6.1) — mapeamento fixo:
| Correspondência | Nível de bind |
| --- | --- |
| Completa | Bind direto |
| Parcial | Bind parcial |
| Divergente | Bind conceitual (existe estrutura relacionada, sem integração suficiente ou com semântica diferente) |
| Inexistente | Sem bind |
| Não verificável | — (não usada nesta matriz: sempre foi possível classificar a PoC) |

**Prioridade:** P0 bloqueador (impede validar a especificação ou quebra fluxo essencial/dados/segurança) · P1 alta (necessário à v1 social/core) · P2 média · P3 baixa.
**Dependências:** TR-xxx (outra linha), D-xx (`OPEN_DECISIONS.md`), GAP-x-xx (`DOMAIN_AND_ARCHITECTURE_GAPS.md`).
